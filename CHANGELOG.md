# Changelog

## 1.0.0 — 2026-11-18

First release.

- 9 adjustment sliders (exposure, brightness, contrast, highlights, shadows, saturation, vibrance, warmth, hue)
- 14 hand-written filters, including 3×3 convolution blur/sharpen
- 21 presets in 5 packs
- Recipes: save, copy, download, import — shareable as plain JSON text
- Crop with draggable handles, rule-of-thirds grid, aspect presets
- Rotate 90°, flip horizontal/vertical
- Undo/redo history (50 states)
- Zoom + pan, fit-to-view, before/after split slider and hold-to-compare
- Export PNG / JPEG / WebP at chosen quality, full resolution
- Full keyboard shortcut set
- 6 generated abstract sample photos, 8 bundled recipes
- 91 unit tests, all passing
