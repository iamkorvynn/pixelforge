# Changelog

## 1.0.0 — 2026-11-18

First release.

- 9 adjustment sliders (exposure, brightness, contrast, highlights, shadows, saturation, vibrance, warmth, hue)
- 19 hand-written filters, including 3×3 convolution blur/sharpen and live strength sliders
- 29 presets in 7 packs
- Recipes: save, copy, download, import, deep-link sharing — shareable as plain JSON text
- Crop with draggable handles, rule-of-thirds grid, aspect presets
- Rotate 90°, flip horizontal/vertical, free straighten (−45°…+45°)
- Live histogram with clipping stats
- Undo/redo history (50 states)
- Zoom + pan, fit-to-view, before/after split slider and hold-to-compare
- Export PNG / JPEG / WebP at chosen quality and size (0.25×–2×)
- Session restore from localStorage
- Full keyboard shortcut set
- 11 generated abstract sample photos, 11 bundled recipes
- 121 unit tests, all passing
