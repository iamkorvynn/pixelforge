# Keyboard shortcuts

| Keys | Action |
| --- | --- |
| `Ctrl/⌘ + Z` | Undo |
| `Ctrl/⌘ + Shift + Z` / `Ctrl + Y` | Redo |
| `Ctrl/⌘ + O` | Open image |
| `Ctrl/⌘ + S` / `Ctrl/⌘ + E` | Export image |
| `Ctrl/⌘ + 0` | Reset all edits |
| `R` | Rotate 90° clockwise |
| `H` | Flip horizontal |
| `V` | Flip vertical |
| `C` | Toggle crop mode |
| `A` | Toggle before/after split slider |
| `B` (hold) | Show the original while held |
| `F` | Fit image to view |
| `0` | Zoom to 100% |
| `+` / `−` | Zoom in / out |
| `?` | Show the shortcut list |

Shortcuts are ignored while you are typing in a text field. Mouse and touch work everywhere: wheel zooms at the cursor, drag pans, crop handles drag, and the compare divider drags.
